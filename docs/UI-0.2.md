# 0.2.0 界面与试拍调整

实现依据为用户确认的玻璃容器布局，以及 Camera M 的条件面板、Darkroom 的内容与工具层次。正式 App 使用 SwiftUI 原生 `glassEffect`、`GlassEffectContainer`、玻璃按钮、系统导航和标签栏；没有把生成图片或浏览器的模糊效果贴进 App。

- 拍摄页：1× 物理主摄，完整竖向 3:4 取景矩形；控件放在画幅外。正常字体下根据可用高度等比例缩放，大字体下允许滚动，不裁切取景来塞入按钮。
- 结果页：两台相机各自的玻璃参数卡片，固定排列光圈、快门、ISO。框只在主体确认或重选时出现；“测光关注区域”不等同于单反合焦。首次生成本次结果时回到顶部，后续调整与撤销保持阅读位置。
- 试拍调整：选择“人物模糊”“景深不足”或补偿后先显示新旧参数，确认后才应用。无解的新增调整不能应用，恢复初始仍可恢复并展示原有冲突。
- 回退：每台相机独立保存完整调整快照，包括曝光补偿、快门／景深要求、调整次数和变化说明。“撤销上一步”恢复上一份快照；“恢复初始”清除当前该机调整，也可撤销这次恢复。撤销栈只属于当前拍摄，重拍或清除会重置。
- 高 ISO：显示保留该快门和光圈所需的 ISO 与取舍，没有人为压低 ISO。无法满足条件时使用具体的现场说明及备选调整。
- 历史、设置、校准与联网配置：玻璃容器与原生控件；历史仍保留最终参数、拍摄条件和校准版本。
- 辅助显示：降低透明度时自定义容器提供不透明背景，系统玻璃按钮遵循系统设置；大字体参数转纵向排列。背景仅来自本次本机预览，不包含设计稿的网络素材。

测试增加完整快照撤销、双机独立、恢复及撤销恢复、迟到预览拒绝、重复应用拒绝、无解拒绝、取景比例和主体变化取消求解；UI 测试增加调整预览／应用／回退流程及截图。

iOS 26／27 各 32 项单元／图像／网络／回退测试和 5 项 UI 测试已通过，已生成 0.2.0 build 12 未签名 IPA；纯 Swift 包另有 11 项测试通过。iOS 27 当前已完成 Xcode 27.0 编译与模拟器测试，真机兼容性仍待验收。原生截图直接导出 XCTest 附件，未用生图模型重绘。具体提交、测试数量、产物链接和 IPA 校验值见 [VALIDATION.md](VALIDATION.md)。真机的玻璃效果、取景边界和 RAW 主体对应仍需侧载验收。
